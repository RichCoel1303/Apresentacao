## 📌 Projetos em destaque

### 🧑‍🏫 [ProfHelp!](https://github.com/RichCoel1303/ProfHelp) — `JavaScript · Firebase · Netlify`
Plataforma web **publicada** que gera provas individuais e aleatórias em PDF para cada aluno, a partir de um banco de perguntas próprio (com filtros por matéria, série e bimestre) e exporta a turma em ZIP com gabarito. Inclui controle de acesso por perfil (administrador, coordenador e professor) e é um app instalável (PWA).
🔗 **Demo:** [profhelp-provas.netlify.app](https://profhelp-provas.netlify.app)
